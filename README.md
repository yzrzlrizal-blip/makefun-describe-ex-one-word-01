One word that describes an ex: **unsubscribe** — the verdict you give a former partner the way you give a newsletter you never signed up for. One click, no reply, gone from the inbox for good.

## Run it

```sh
python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
